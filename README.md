# 🧠 Suicide Data Analysis in Mexico | MCP + Data Analytics

## 📌 About the Project

This project is the **first step in developing my own MCP**, combining **AI, data analytics, and Power BI**.

The first stage focuses on exploring a dataset related to **registered suicides in Mexico**, looking for relevant patterns, trends, and insights.

## ⚠️ Data Limitations

The dataset does not include the most recent years, and its coverage may not fully represent the actual number of registered cases. Therefore, the results should be interpreted with caution.

## 🛠️ Technologies

**Python | Pandas | Power BI | MCP | AI**
